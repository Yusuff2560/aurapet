# AuraPet 🐾

AuraPet is a digital keychain virtual pet project inspired by modern digital companion concepts (such as Starboy/lilguy.net digital pets).

## Overview
- **Concept:** Portable digital pet device / virtual keychain companion.
- **Features:** Interactive pet care, digital animations, customizable statuses, and compact keychain form factor.
- **Status:** Active development & concept planning.
