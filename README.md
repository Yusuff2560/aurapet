# 🐾 AuraPet (Star-Buddy)

ESP32-S3 tabanlı, dokunulduğunda mırlayan, ekranda duygusal yüz ifadeleri gösteren giyilebilir/taşınabilir interaktif yapay zeka evcil hayvan projesi.

## 🛠️ Donanım Bileşenleri
* **İşlemci & Ekran:** Seeed Studio XIAO ESP32S3 Sense + Seeed 1.28" Round Display (veya Waveshare ESP32-S3-Touch-LCD-1.28)
* **Pil:** 502030 LiPo Şarjlı Pil (3.7V 250 mAh)
* **Haptik/Mırlama:** 1027 Yassı Para Tipi Titreşim Motoru
* **Ses:** MAX98357A I2S Amfi + 1511 Mikro Telefon Hoparlörü
* **Dokunma:** TTP223 Kapasitif Dokunmatik Modül
